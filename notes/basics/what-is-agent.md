# 什么是 Agent

## 定义

AI Agent（智能体）是一种能够**感知环境、做出决策并采取行动**以完成目标的人工智能系统。与传统的一问一答式 LLM 不同，Agent 具备主动规划和持续执行的能力。

> Agent = LLM 大脑 + 工具调用 + 记忆系统 + 规划能力

## 核心组成

Agent 通常由以下四个模块构成：

| 模块 | 功能 | 举例 |
|------|------|------|
| **大脑（LLM）** | 理解输入、推理规划、生成决策 | GPT-4、Claude、Gemini |
| **工具（Tools）** | 执行具体操作，与外部世界交互 | 搜索、代码执行、API 调用 |
| **记忆（Memory）** | 存储和检索历史信息 | 短期上下文、长期向量数据库 |
| **规划（Planning）** | 将复杂任务拆解为可执行步骤 | CoT、ReAct、Tree of Thoughts |

## 与传统 LLM 的对比

**传统 LLM 调用：**
```
用户输入 → LLM → 文本输出（结束）
```

**Agent 运行循环：**
```
目标输入 → 规划 → 选择工具 → 执行 → 观察结果 → 继续规划 → ... → 完成目标
```

Agent 的核心在于这个**循环（Loop）**——它会不断地"思考-行动-观察"，直到任务完成。

## Agent 的能力边界

Agent 擅长处理：
- 需要多步骤完成的复杂任务
- 需要实时信息（搜索、查询数据库）的任务
- 需要执行代码或调用 API 的任务
- 需要跨工具协作的工作流

Agent 当前的局限：
- 长链路任务中容易累积错误
- 工具调用失败时缺乏健壮的错误恢复
- 成本较高（多轮 LLM 调用）
- 不确定性较大，难以保证每次结果一致

## 小结

理解 Agent 最关键的一点：**它不是"更聪明的聊天机器人"，而是一个能够自主完成任务的执行系统**。LLM 是它的大脑，但 Agent 的价值在于它能真正"做事"而不仅仅是"说话"。
